# 📋 ПРОМПТ ДЛЯ СТВОРЕННЯ ПРОГРАМИ ТРЕНУВАНЬ

## Мета
Створити детальну програму футбольних тренувань для мобільного додатку. Програма повинна бути структурована, мультимовна (українська, англійська, чеська), **адаптована під вікові категорії** та готова для імпорту в базу даних.

---

## 📊 СТРУКТУРА ДАНИХ

### Ієрархія
```
Програма (Program)
  └── Дні (Days) [1-30]
        └── Секції (Sections) [розминка, основна частина, заминка]
              └── Вправи (Exercises)
```

---

## 🏆 1. ПРОГРАМА (Program)

| Поле | Тип | Обов'язкове | Опис |
|------|-----|-------------|------|
| `title_uk` | string | ✅ | Назва українською |
| `title_en` | string | ✅ | Назва англійською |
| `title_cs` | string | ✅ | Назва чеською |
| `description_uk` | string | ✅ | Опис українською (1-2 речення) |
| `description_en` | string | ✅ | Опис англійською |
| `description_cs` | string | ✅ | Опис чеською |
| `category` | enum | ✅ | Категорія програми |
| `difficulty` | enum | ✅ | Рівень складності |
| `duration_days` | number | ✅ | Кількість днів (зазвичай 30) |
| `icon` | string | ✅ | Емодзі іконка |
| `cover_image` | string | ❌ | URL зображення обкладинки |
| `age_categories` | array | ✅ | Масив вікових категорій |
| `min_age` | number | ❌ | Мінімальний вік (опціонально) |
| `max_age` | number | ❌ | Максимальний вік (опціонально) |

### Допустимі значення age_categories:
- `U8` - до 8 років (5-7 років)
- `U10` - до 10 років (8-9 років)
- `U12` - до 12 років (10-11 років)
- `U14` - до 14 років (12-13 років)
- `U16` - до 16 років (14-15 років)
- `U18` - до 18 років (16-17 років)
- `Senior` - дорослі (18+ років)

### Допустимі значення category:
- `explosiveness` - вибуховість, швидкість
- `technique` - техніка володіння м'ячем
- `endurance` - витривалість
- `strength` - сила
- `agility` - спритність
- `shooting` - удари по воротах
- `dribbling` - дриблінг

### Допустимі значення difficulty:
- `beginner` - початківець
- `intermediate` - середній
- `advanced` - просунутий

### Рекомендовані іконки:
- ⚡ - вибуховість, швидкість
- ⚽ - техніка, загальне
- 🏃 - витривалість, біг
- 💪 - сила
- 🎯 - точність, удари
- 🔥 - інтенсивні тренування
- 🌟 - спеціальні програми

## 📅 2. ДЕНЬ (Day)

| Поле | Тип | Обов'язкове | Опис |
|------|-----|-------------|------|
| `day_number` | number | ✅ | Номер дня (1-30) |
| `title_uk` | string | ✅ | Назва дня українською |
| `title_en` | string | ✅ | Назва дня англійською |
| `title_cs` | string | ✅ | Назва дня чеською |
| `focus_uk` | string | ✅ | Фокус тренування українською |
| `focus_en` | string | ✅ | Фокус тренування англійською |
| `focus_cs` | string | ✅ | Фокус тренування чеською |
| `intensity` | enum | ✅ | Інтенсивність |
| `location` | enum | ✅ | Місце проведення |
| `duration_minutes` | number | ✅ | Тривалість в хвилинах |

### Допустимі значення intensity:
- `low` - низька (відновлення, розтяжка, легка активність)
- `medium` - середня (координація, техніка, помірне навантаження)
- `high` - висока (інтенсивні вправи, спринти, силові)

### Допустимі значення location:
- `home` - вдома/у дворі (без спеціального обладнання)
- `field` - футбольне поле (потрібен простір, ворота)

### Рекомендована тривалість:
- `low` intensity: 30-45 хвилин
- `medium` intensity: 40-50 хвилин
- `high` intensity: 45-60 хвилин
- День відпочинку: 0 хвилин

| Поле | Тип | Обов'язкове | Опис |
|------|-----|-------------|------|
| `order_index` | number | ✅ | Порядок секції (починається з 0) |
| `title_uk` | string | ✅ | Назва секції українською |
| `title_en` | string | ✅ | Назва секції англійською |
| `title_cs` | string | ✅ | Назва секції чеською |
| `duration_minutes` | number | ❌ | Тривалість секції в хвилинах |

### Стандартні секції (обов'язкові для кожного дня):

| # | Українська | English | Česky | Тривалість |
|---|------------|---------|-------|------------|
| 0 | Розминка | Warmup | Rozcvička | 5-10 хв |
| 1 | Основна частина | Main part | Hlavní část | 20-35 хв |
| 2 | Заминка | Cooldown | Zklidnění | 5-10 хв |

### Додаткові секції (опціонально):
- `Тест балансу` / `Balance Test` / `Test rovnováhy`
- `М'яч + координація` / `Ball + Coordination` / `Míč + Koordinace`
- `Спринти` / `Sprints` / `Sprinty`
- `Силова частина` / `Strength part` / `Silová část`
- `Техніка з м'ячем` / `Ball technique` / `Technika s míčem`
- `Плейометрика` / `Plyometrics` / `Plyometrie`

| `description_uk` | string[] | ✅ | **МАСИВ** кроків українською |
| `description_en` | string[] | ✅ | **МАСИВ** кроків англійською |
| `description_cs` | string[] | ✅ | **МАСИВ** кроків чеською |
| `exercise_type` | enum | ✅ | Тип вправи |
| `sets_uk` | string | ❌ | Підходи українською |
| `sets_en` | string | ❌ | Підходи англійською |
| `sets_cs` | string | ❌ | Підходи чеською |
| `reps_uk` | string | ❌ | Повторення українською |
| `reps_en` | string | ❌ | Повторення англійською |
| `reps_cs` | string | ❌ | Повторення чеською |
| `rest_seconds` | number | ❌ | Відпочинок між підходами (секунди) |
| `timer_duration` | number | ❌ | Час виконання вправи (секунди) |
| `input_label_uk` | string | ❌* | Підпис поля введення українською |
| `input_label_en` | string | ❌* | Підпис поля введення англійською |
| `input_label_cs` | string | ❌* | Підпис поля введення чеською |
| `note_uk` | string | ❌ | Примітка/порада українською |
| `note_en` | string | ❌ | Примітка/порада англійською |
| `note_cs` | string | ❌ | Примітка/порада чеською |
| `video_url` | string | ❌ | URL відео з демонстрацією |

*`input_label` обов'язкове якщо `exercise_type` = "input"

### Допустимі значення exercise_type:

| Тип | Опис | Коли використовувати |
|-----|------|---------------------|
| `checkbox` | Галочка "виконано" | Звичайні вправи без вимірювання результату |
| `input` | Поле для введення числа | Тести, вимірювання результату (час, кількість) |
| `timer` | Таймер зворотнього відліку | Вправи на час з автоматичним таймером |

### Важливо про description:
⚠️ **description - це МАСИВ рядків, НЕ один рядок!**

```json
// ✅ ПРАВИЛЬНО:
"description_uk": [
  "Крок 1: Стань прямо",
  "Крок 2: Підніми коліно",
  "Крок 3: Опусти ногу"
]

// ❌ НЕПРАВИЛЬНО:
"description_uk": "Стань прямо, підніми коліно, опусти ногу"
```

### Важливо про час:
⚠️ **timer_duration та rest_seconds вказуються в СЕКУНДАХ!**

| Час | Секунди |
|-----|---------|
| 30 секунд | 30 |
| 1 хвилина | 60 |
| 1.5 хвилини | 90 |
| 2 хвилини | 120 |
| 3 хвилини | 180 |
| 5 хвилин | 300 |

## 🔄 ПРОГРЕСІЯ СКЛАДНОСТІ

### Тиждень 1-2 (Адаптація):
- Менше повторень
- Більше відпочинку
- Фокус на техніці
- Тести для визначення рівня

### Тиждень 3-4 (Розвиток):
- Збільшення повторень на 20-30%
- Зменшення відпочинку
- Додавання складніших варіацій
- Комбіновані вправи

### Тиждень 5 (Пік + Відновлення):
- Максимальна інтенсивність на початку
- Фінальні тести
- Порівняння з початковими результатами
- Рекомендації для подальшого розвитку

- [ ] Секції мають правильний order_index (0, 1, 2...)
- [ ] intensity відповідає типу дня
- [ ] duration_minutes реалістична

### Вправи:
- [ ] description - це МАСИВ рядків, не один рядок
- [ ] timer_duration в СЕКУНДАХ
- [ ] rest_seconds тільки якщо є sets
- [ ] input_label тільки якщо exercise_type = "input"
- [ ] order_index починається з 0 в кожній секції

### Баланс програми:
- [ ] ~2-3 дні low intensity на тиждень
- [ ] ~2 дні medium intensity на тиждень
- [ ] ~2 дні high intensity на тиждень
- [ ] 1 день повного відпочинку на тиждень

## 📚 КОРИСНІ ВПРАВИ ЗА КАТЕГОРІЯМИ

### Розминка:
- Легкий біг / ходьба
- Обертання суглобів (гомілкостоп, коліна, таз, плечі)
- Динамічна розтяжка (випади, махи ногами)
- Стрибки на місці
- Біг з високим підніманням колін

### Вибуховість:
- Присідання з вистрибуванням
- Випади з вистрибуванням
- Берпі
- Бокс-джампи (стрибки на платформу)
- Спринти 10-30м
- Старти з різних позицій

### Координація:
- Баланс на одній нозі
- Годинник (малювання ногою)
- Драбинка (footwork)
- Стрибки через лінію
- Вправи з закритими очима

### Техніка з м'ячем:
- Жонглювання (права/ліва/чергування)
- Пас в стіну
- Ведення м'яча
- Фінти (степовер, ножиці, еластико)
- Удари по воротах

### Сила:
- Присідання
- Випади
- Віджимання
- Планка
- Підйоми на носки

### Заминка:
- Статична розтяжка
- Глибоке дихання
- Розслаблення м'язів
- Легка ходьба

## 📅 СИСТЕМА ПЕРСОНАЛІЗОВАНОГО РОЗКЛАДУ

### Типи тренувальних днів:
- `full_training` - Повне тренування (45-60 хв)
- `light_training` - Легке тренування (20-30 хв)
- `skills_only` - Тільки техніка (15-20 хв)
- `recovery` - Відновлення (10-15 хв)
- `match_prep` - Підготовка до матчу
- `post_match` - Після матчу
- `team_training` - Командне тренування
- `match_day` - День матчу
- `rest` - Повний відпочинок

### Рекомендації за віком:

| Вік | Тренувань/тиждень | Тривалість | Інтенсивність |
|-----|-------------------|------------|---------------|
| U8  | 2-3 | 20-30 хв | Низька, гра |
| U10 | 2-4 | 30-40 хв | Низька-середня |
| U12 | 3-4 | 40-50 хв | Середня |
| U14 | 3-5 | 45-60 хв | Середня-висока |
| U16+ | 4-6 | 60-90 хв | Висока |

### Правила автоматичного розподілу:

**ЗАБОРОНЕНО:**
- 2 важких тренування поспіль
- Тренування за день до матчу (тільки легке)
- Більше 5 тренувальних днів на тиждень

**РЕКОМЕНДОВАНО:**
- Після командного тренування → відпочинок або легке
- Перед матчем → легка техніка або відпочинок
- Після матчу → відновлення
- Мінімум 2 дні відпочинку на тиждень
